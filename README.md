# Система автоматического слежения за объектами

Программная часть системы видеонаблюдения с управлением сервоплатформой на Arduino. Захватывает видеопоток с камеры, обнаруживает объекты нейросетью YOLOWorld, принимает голосовые команды и передаёт управляющие углы на микроконтроллер по Serial.

---

## Требования к системе

| Компонент | Минимум |
|---|---|
| ОС | Windows 11 / Linux |
| Python | **3.12** (строго) |
| GPU | NVIDIA с CUDA 12.6+ |
| ОЗУ | 8 ГБ |
| Диск | 10 ГБ свободного места |

---

## Установка и запуск

### 1. Python 3.12

Проверьте версию:
```bash
python --version
```

Скачайте Python 3.12 с [python.org](https://www.python.org/downloads/) и установите (поддерживается **только версия 3.12**).

### 2. pip и uv

```bash
py -m ensurepip --upgrade
winget install --id=astral-sh.uv -e
```

### 3. Зависимости проекта (PyTorch + CUDA 12.6)

```bash
uv sync
```

`uv` автоматически прочитает `pyproject.toml` и установит все зависимости, включая PyTorch из индекса `pytorch-cu126`.

### 4. Языковая модель Vosk

Скачайте модель [`vosk-model-small-ru-0.22`](https://alphacephei.com/vosk/models) и распакуйте в корневую директорию проекта:

```
project/
├── vosk-model-small-ru-0.22/
├── main.py
└── ...
```

### 5. Запуск

```bash
uv run python main.py
```

## Прошивка микроконтроллера (Arduino)

1. Установите [Arduino IDE](https://www.arduino.cc/en/software).
2. Откройте файл `platform.ino` в Arduino IDE.
3. Подключите платформу:
   - Кабель питания → разъём питания → розетка 220 В
   - Кабель AM/MicroBM → разъём micro USB type B → USB-порт ПК
4. Выберите **тип платы** и **COM-порт** (ориентируйтесь на метку USB в названии порта).
5. Нажмите кнопку загрузки (Upload).

## Голосовые команды

| Команда | Действие |
|---|---|
| `найти <объект>` / `найди` / `искать` / `ищи` | Заменить текущий объект поиска |
| `добавить <объект>` / `добавь` / `плюс` | Добавить объект к списку |
| `удалить` / `убрать` / `минус` | Удалить последний объект из списка |
| `следить <id>` / `следи` / `след` | Зафиксировать слежение на объекте по ID трекинга |
| `приблизить` / `увеличить` / `вперёд` | Зум +0.5 (до x5.0) |
| `отдалить` / `уменьшить` / `назад` | Зум −0.5 (до x1.0) |
| `уверенность <процент>` / `порог` | Установить порог уверенности модели |
| `выйти` / `выход` / `стоп` | Завершить работу системы |

## Интерфейс

При запуске открывается окно с видеопотоком в реальном времени. На изображение наносится:

- текущий уровень зума (левый верхний угол)
- порог уверенности модели
- ID отслеживаемого объекта (если активен режим слежения)
- рамки вокруг обнаруженных объектов с классом, уверенностью и ID трекинга

В терминале выводится список доступных голосовых команд, система непрерывно слушает микрофон.

## Параметры запуска (`main.py`)

```python
Platform((1920, 1080), (58, 33)).run()
```

| Параметр | Значение по умолчанию | Описание |
|---|---|---|
| `size` | `(1920, 1080)` | Разрешение камеры |
| `fov` | `(58, 33)` | Угол обзора камеры (°) по X и Y |
| `init_conf` | `0.1` | Начальный порог уверенности |

Видеоустройство задаётся в `IOOperator`: по умолчанию `/dev/video2`.  
Serial-порт задаётся в `SerialWriter`: по умолчанию `/dev/ttyUSB0`, baudrate `9600`.
